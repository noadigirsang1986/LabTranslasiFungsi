Lab Translasi Fungsi

g(x) = f(x − h) + k  ·  T = (h, k)

1. Pilih jenis fungsi

2. Atur nilai fungsi asal

3. Geser dengan slider

2 h > 0 geser ke kanan, h < 0 geser ke kiri
1 k > 0 geser ke atas, k < 0 geser ke bawah

4. Persamaan

Vektor translasi21
g(x) hasil translasi f(x) asal vektor T asimtot kurva target

Tip: seret grafik langsung di bidang kartesius untuk menggeser kurva. Nilai h dan k ikut berubah dengan kelipatan 0,5.

Sifat sebelum → sesudah

Pergeseran titik

Setiap titik (a, f(a)) pada f berpindah ke (a + h, f(a) + k) pada g.

Tantangan: tebak translasinya

Muncul kurva target bergaris oranye. Atur h dan k sampai kurva hijau menimpanya, lalu periksa.

Benar 0 dari 0 percobaan
